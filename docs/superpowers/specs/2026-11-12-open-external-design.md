# Desenho aprovado: Abrir com programa externo
Extensão VS Code para arquivos locais no Windows. Menu do Explorer, do editor e paleta oferecem “Abrir com programa externo…”. Quick Pick pesquisável lista aplicativos associados pelo Windows ao tipo. Selecionar abre nesse programa; sem associações, oferece diálogo nativo. TypeScript, PowerShell 5.1 e APIs Shell via C# empacotado. Sem dependências adicionais de execução, rede, telemetria ou mudanças nas associações padrão.
Abordagens: diálogo nativo apenas (mais simples, seleção fora do VS Code) versus lista integrada com associações Windows (escolhida). Implementação escolhe SHAssocEnumHandlers e IAssocHandler.Invoke, evitando interpretar comandos do Registro. Programas sem associação registrada podem não aparecer. Exclui arquivos remotos WSL/SSH, diretórios e documentos sem arquivo salvo.
Entrega: fontes, VSIX e instruções. Testes automatizados em Linux não substituem validação real do Shell Windows; incluir checklist manual.
